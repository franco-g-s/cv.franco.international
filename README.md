# cv.franco.international

Standalone CV — a single-page, print-optimized HTML/CSS document sourced from my private Obsidian vault.

🌐 **Live site:** [cv.franco.international](https://cv.franco.international)

Part of a three-site personal web presence:
- [franco.international](https://franco.international) — personal hub
- [garden.franco.international](https://garden.franco.international) — digital garden
- **[cv.franco.international](https://cv.franco.international)** — this CV

## Design

Apple-inspired black-on-white typography. Inter font throughout. Sections: About, Education, Experience, Skills (with Languages), International Background.

- Weight 200 headings, generous whitespace, tight letter-spacing
- Subtle blue accent `#0066cc` for section labels and links
- Planned/upcoming entries styled in grey with an inline badge
- Print-optimized: `@media print` hides the print button; `break-inside: avoid` per entry prevents mid-entry page breaks

## Tech Stack

No framework. Single `index.html` + `style.css`. Deployed via GitHub Pages and GitHub Actions.

## Local Development

Open `index.html` directly in a browser — no build step required.
